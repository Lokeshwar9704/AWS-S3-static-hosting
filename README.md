# ☁️ AWS S3 Static Website Hosting

## 📌 Project Overview

This project focuses on hosting a static website using **Amazon Simple Storage Service (Amazon S3)**.

The objective is to deploy an HTML webpage using Amazon S3 static website hosting. The project involves creating an S3 bucket, uploading website files, enabling static website hosting, configuring public access permissions, and accessing the deployed website through the S3 website endpoint.

This project demonstrates practical experience with AWS cloud storage, website deployment, bucket policies, and cloud hosting fundamentals.

## 🎯 Project Objectives

- Create an Amazon S3 bucket.
- Prepare a static HTML webpage.
- Upload website files to the S3 bucket.
- Enable static website hosting.
- Configure public access settings.
- Create an S3 bucket policy to allow public read access.
- Access and test the deployed website using the S3 website endpoint.

## 🛠️ Technologies Used

- **Amazon S3** – Cloud storage and static website hosting.
- **HTML** – Website structure and content.
- **AWS IAM / Bucket Policies** – Access permissions and resource security.
- **AWS Management Console** – Cloud resource configuration.

## ⚙️ Implementation Steps

### Step 1: Create an Amazon S3 Bucket

Created a new Amazon S3 bucket to store the static website files.

### Step 2: Upload Website Files

Prepared an HTML webpage and uploaded the website file (`index.html`) to the S3 bucket.

### Step 3: Check the File Location

Verified that the website file was successfully uploaded and available inside the S3 bucket.

### Step 4: Enable Static Website Hosting

Enabled static website hosting in the S3 bucket properties and configured the index document.

### Step 5: Configure Public Access

Updated the bucket's public access settings to allow visitors to access the static website.

### Step 6: Add the Bucket Policy

Configured an S3 bucket policy to allow public read access to the website objects.

### Step 7: Test the Website

Opened the S3 static website endpoint in a web browser and verified that the webpage was successfully deployed and accessible.
